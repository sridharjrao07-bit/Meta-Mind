# Phase 1 handoff

Phase 1 starts with schema review. It must not begin until the Phase 0 exit
checklist is signed.

## Inputs from Phase 0

- [ ] Ratified model decision and candidate versions
- [ ] Ratified grounding budgets and measured characteristics
- [ ] Ratified auth recommendation
- [ ] Ratified weekly economics ceiling
- [ ] Ratified notification decision
- [ ] Frozen rubric and verdict taxonomy
- [ ] Golden set v0 with 30 human labels
- [ ] Injection and safety first-pass results

## Phase 1 first acts

- [ ] Review schema against the plan of record
- [ ] Decide explanation-version mastery decay rule
- [ ] Select migration tool and test up/down migrations
- [ ] Define route inventory and negative authorization cases
- [ ] Define event validation and retention boundaries
- [ ] Record the handoff evidence in the weekly review
